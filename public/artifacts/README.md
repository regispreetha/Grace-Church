### Staff

## Image Guidelines

- **Format**: PNG or JPG
- **Dimensions**:
  - Hero images: 1920x1080px (16:9 ratio)
  - Card images: 800x600px (4:3 ratio)
  - Staff photos: 400x400px (square)
- **File size**: Keep under 500KB for web performance
- **Quality**: High resolution but optimized for web

## Placeholder Images

Until you add the actual images, you can use placeholder images from:
- https://placehold.co/
- https://unsplash.com/ (free stock photos)
- https://picsum.photos/ (random placeholder images)

## Adding Images

Simply drop your images into this directory with the exact filenames listed above.
